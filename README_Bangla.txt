SNELIPE WEBSITE — QUICK START (Bangla)

এই ZIP-এর মধ্যে website-এর সব ফাইল আছে।

ফাইল:
- index.html = website-এর লেখা ও sections
- style.css = design, colour, mobile layout
- script.js = ছোট JavaScript

কম্পিউটারে preview:
1. ZIP extract করুন।
2. snelipe_website folder খুলুন।
3. index.html-এ double click করুন।
4. Browser-এ website preview হবে।

Publish করার আগে অবশ্যই:
1. index.html ফাইলে https://wa.me/8801XXXXXXXXX খুঁজুন।
2. 8801XXXXXXXXX-এর জায়গায় আপনার WhatsApp নম্বর country code সহ দিন।
   উদাহরণ: বাংলাদেশের নম্বর 01712345678 হলে লিখবেন 8801712345678
3. Facebook ও Instagram link পরে footer-এ যোগ করতে পারেন।
4. Products এলে placeholder cards-এর জায়গায় product photo, name, price ও description বসাতে হবে।
5. Website এখন catalogue/WhatsApp-order starter; online payment/cart/stock management এখনো যুক্ত নেই।

Cloudflare Pages-এ publish:
1. Cloudflare dashboard-এ login করুন।
2. Workers & Pages → Create application → Pages → Upload assets নির্বাচন করুন।
3. Extract করা folder-এর ভেতরের website files upload করুন (index.html, style.css, script.js)।
4. Deploy করুন।
5. Pages project-এর Custom domains-এ snelipe.com ও www.snelipe.com যুক্ত করুন।
6. DNS screen-এ Cloudflare যে records দেখায় সেগুলো confirm করুন।

গুরুত্বপূর্ণ:
- এই starter website-এ কোনো fake product photo বা invented product price নেই।
- Product placeholder artwork CSS দিয়ে তৈরি।
- Domain connect/publish করতে আপনার Cloudflare account-এ আপনাকেই login করতে হবে।
